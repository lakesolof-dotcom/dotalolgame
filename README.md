# Python MOBA prototype (без Ursina)

Небольшой прототип игры в стиле MOBA (LoL/Dota-like) на чистом Python через `tkinter`.

## Запуск

```bash
python3 main.py
```

## Управление

- `WASD` или `стрелки` — движение героя
- `Q` — круговой магический удар (есть визуальное кольцо)
- `E` — лечение героя (отдельная кнопка, не конфликтует с движением)

## Что есть в прототипе

- узнаваемые герои в стиле приложенных мем-котов: **Яспер** и **Хитрый кот**
- визуальные эффекты способностей и попаданий
- волны миньонов
- 2 башни
- здоровье/мана/золото/KD
- возрождение героя
- условие победы по уничтожению башни
